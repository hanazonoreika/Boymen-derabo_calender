# ボイメン5人・でらボ 統合イベントカレンダー

## ファイル構成
- `index.html` : カレンダー画面
- `scrape.py` : 公式サイトから公開予定を取得する処理
- `data/events.json` : 自動生成される予定データ
- `.github/workflows/update-and-deploy.yml` : 6時間ごとの取得とGitHub Pages公開

## GitHubへの入れ方
このZIPの中身をリポジトリのルートに置いてください。特に、ワークフローは `python scrape.py` を実行する設定です。`scripts/scrape.py` ではありません。

## 注意
- 公式サイトの構造変更やアクセス制限により、取得件数が変わることがあります。
- 日付を確定できない告知は、誤った日付に登録しないよう自動登録しません。
- メンバー判定はイベント名を優先し、月全体のテキストから推測しません。
- 手動予定はブラウザのローカル保存です。公式取得データとは別に管理されます。
- 非公式のファン向けカレンダーです。詳細・変更・中止は必ず各公式リンクで確認してください。
